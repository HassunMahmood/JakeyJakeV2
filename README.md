# Jakey Jake Y2K Fan Club

A bright, playful, completely unserious React fan-club landing page.

## Run locally

```bash
cd frontend
npm install
npm start
```

Then open the local URL shown by Create React App.

## Included interactions

- Join-club counter button
- Mood selector with dynamic colour and copy
- Scrapbook gallery
- Three-question Jake-era quiz
- Responsive mobile layout

## Image and font assets

The app intentionally uses publicly hosted image and Google Fonts URLs in the CSS/React data so the project stays lightweight and contains no generated or binary media files. An internet connection is required for those remote assets; the UI and interactions render locally without an API or backend.
